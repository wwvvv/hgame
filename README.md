# HGAME · 游戏中心制作工具与发行规范

> **2026-10-01 已确认方向：acg-go 保留社区主站和首页，hgame 作为站内 `/games` 游戏中心，不独立运营第二个网站。**

此仓库继续维护本地游戏制作 Skill、模板方案、发行契约和校验工具。原 Next.js 页面保留为历史技术样板与移植参考；不再在这里建设第二套账号、订单、数据库或后台。

正式面向玩家的游戏页面与 Go API 在 `wwvvv/acg-go` 实现。首批集成见 [acg-go PR #38](https://github.com/wwvvv/acg-go/pull/38)，它仍是待整仓验收的功能分支，不代表已经部署或开启收费。

## 当前分工

| 位置 | 职责 |
|---|---|
| acg-go 主站 | 社区、账号、权限、评论、通知与原运营后台 |
| acg-go `/games` | 目录、详情、试玩、未来游戏库与购买入口 |
| acg-go Go 后端 | 游戏目录/版本、未来审核、订单和购买权益 |
| 本仓 `skills/` | 本地 Codex / Claude 等客户端的制作工作流 |
| 本仓 `contracts/` 与 `scripts/` | 游戏包元信息及校验工具，不是生产交易服务 |
| 独立运行来源 | 托管已审核的游戏运行包，不承载主站凭据 |

生产方案以 [社区游戏中心整合决策](docs/ACG_GO_INTEGRATION.md) 为准。2026-09-30 的独立网站架构、数据模型、路由、部署和路线图保留为历史设计；与新决策冲突时不再执行旧方案。

## 制作和发行流程

本地 Skill + 固定模板 → 可玩草稿 → 局部修改与真实测试 → 独立 Demo/完整版包 → 人工审核 → 社区游戏中心。

不开发在线 AI 工作台、运行时付费角色聊天或多引擎自动适配。基础 Skill 不包含模型额度；第三方素材和工具使用需要满足对应授权与服务条件。

## 当前集成阶段

acg-go P0 添加可关闭的目录、详情、隔离试玩和只读配置检查；临时由运营方 JSON 配置作品。主站首页不替换、账号不迁移、数据库不改动。

正式作品CRUD、上传审核、支付、购买权益、年龄核验、正式WebGAL模板和云存档尚未完成。当前技术样板为非露骨原创内容，不是商业游戏，也不能直接收费上线。

## 历史技术样板的本地检查

以下命令只服务本仓历史原型和契约回归，不会启动或部署 acg-go 游戏中心。

```bash
npm test
npm run validate:manifest -- contracts/game-manifest.example.json
```

需要打开旧页面时再按原依赖说明安装并运行 `npm run dev`；它不再是正式主站入口。本次整合不删除旧代码、不替换旧 Skill 和契约、不部署公网或启用收费。
