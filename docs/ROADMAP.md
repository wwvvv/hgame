# 开发任务与验收

状态用 TODO / IN_PROGRESS / VERIFIED；不能因存在字段/按钮就标记业务完成。

| 阶段 | 任务 | 验收标准 |
|---|---|---|
| P0 框架 | 当前网站、契约、Skill、文档 | 目录/详情/样板、失效状态、接口拒绝、单元测试、构建和浏览器报告分别记录 |
| P0.1 依赖与 UI | 联网安装冻结 lock；核对 TouchGal 可迁移组件 | 安装可复现，来源记录完整，移动 360/390 与桌面 1440 无溢出 |
| P1 身份与目录 | PostgreSQL/ORM、真实用户、作品/版本/收藏、管理员权限 | 两账户隔离，迁移可回滚，未公开作品无公开 API，草稿与已发布分开 |
| P1.1 正式模板 | 固定 WebGAL 模板、角色/素材、两路线、存读档 | 真机/浏览器实测；Demo->Full 存档迁移有真实测试；不依赖 runtime AI |
| P1.2 交付安全 | 隔离接收、ZIP/路径/哈希/资源/内容检查 | 拒绝恶意包、软链接、泄露凭据、额外未列文件；审核后才可发布 |
| P2 交易 | 单支付商、订单、回调、权益、退款 | 沙箱付款与失败、重复/乱序回调、金额篡改、退款撤销全部测试 |
| P2.1 游戏授权 | 独立来源、私有资源、短会话 | 非购用户无法读完整资产、过期会话失效、下架阻止新启动、主站凭据不泄露 |
| P2.2 运营上线 | 年龄/地区/内容/隐私/支付确认 | 业务政策落实、运营审核、举报流程、备份恢复、限流与依赖审计 |
| P3 可选 | 自助投稿、作者收益、会员库 | 有真实内容规模和需求后单独立项，不列为首发依赖 |

## 测试矩阵

访客/普通用户/作者/管理员；draft/review/published/suspended；demo/full；有/无/过期/撤销权益；新旧 Release；桌面/移动；正常/失败/重复付款；正常/恶意 ZIP。每项必须有明确拒绝或可用结果，不把未知当成功。
