# 安全与上线闸门

## 当前隔离

仅加载仓库内自有非露骨技术样板；iframe 为 `sandbox=allow-scripts`，不赋予同源、弹窗或顶层导航能力。演示页 CSP 禁止网络连接。没有任意上传、真实账户、收款或付费资产。网站基本安全响应头不等于完整 CSP/安全验收。

## 上线前必须完成

- 身份：可靠会话、服务端权限、CSRF/Origin 验证、限流、登录与关键操作审计；无“默认演示用户”。
- 支付：经营主体/内容类别获得服务商明确接受；使用托管支付页，不处理卡号；签名、金额、币种、唯一事件、事务幂等、退款与拒付。
- 年龄与地区：根据经营地区和服务市场确认适用要求，部署适用的年龄保障；勾选 18+ 不是通用合规方案。尽量只存核验结论，不自行收集身份证影像。
- 内容：合法授权、明确成年角色与允许内容范围；禁非法、非自愿与未成年性内容；举报、审核、争议和下架机制。
- 资源：付费内容默认私有；Demo/Full 分离；所有敏感资源而非仅入口鉴权。已下发浏览器的内容不能保证绝对防复制。
- 执行：作品独立来源，不带主站 Cookie；上游来源也不默认可信；禁止作者任意服务器命令/安装钩子；扫码/下载等外部动作单独审查。
- 上传：隔离、配额、恶意压缩包/路径/软链接/MIME/凭据扫描；校验和证明完整性而非来源可信或版权。
- 隐私：玩家记录默认私有，作者只能看聚合统计；日志脱敏，短时令牌不进 URL 长期日志；密码/证件/支付详情不进 Git。
- 运维：HTTPS、代理请求上限、备份恢复演练、密钥轮换、最低权限、依赖锁定与漏洞审查、异常费用报警。

## 支付与法律不是框架开关

不预设 Stripe/PayPal 等通道接受成人业务；不得通过改名积分或工具费掩盖真实内容。代码授权不替代服务商审批、素材版权或区域规则。具体市场与商户未确认前不开放成人内容与交易。

## iframe / postMessage 后续要求

正式游戏会话限定 user/game/release/edition/expiry，服务端签发；桥接仅允许白名单消息，校验 event.source 与精确 origin，不能接受游戏消息修改购买状态。对 opaque-origin demo 当前不使用 postMessage 信任通道。允许存储时重新设计 per-game 来源，避免不同游戏相互读取。

参考：MDN iframe https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe ；支付商限制应上线时直接核对其官方规则。
