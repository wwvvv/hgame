# 产品与商业基线 v0.1

## 确定的方向

HGAME 是面向成年用户的 H5 游戏发行网站，不是模型充值站、AI 角色聊天站或在线游戏开发工作台。前台以作品为中心；作者在本地通过 Skill 和固定模板完成游戏，再提交发行。

首发由运营方统一上架自营/授权作品。允许少量合作作者人工交付，但不建设开放上传执行、自动提现、全站论坛或多级推广。开发与公开仓库仅使用非露骨占位素材。

## 玩家旅程

发现 -> 详情 -> 了解试玩与购买范围 -> 试玩 -> 单作购买 -> 获得服务端访问授权 -> 继续游戏。当前骨架只完成发现/详情/技术试玩，不存在已购权益。

首页：编辑精选、分类与新作，不编造热度。详情：封面、简介、截图、作者、设备支持、语言、版本、内容分级、试玩范围、购买范围。游戏库：已购与收藏必须区分；没有真实账户前展示未接通说明。

## 商业模式

首发免费试玩 + 单作购买。AI 是制作方法，不作为玩家计费单位。固定剧情下每次点击对白不扣点数。将来有稳定内容供给及对应授权后才考虑会员库；已购作品与期限性会员权益分离。

平台自营作品承担制作成本；合作作品采用明确约定的发行分成。80/20 仅为讨论中的测试参数，未锁定，不能写入结算代码。暂不承诺价格、收入预测或“已经验证盈利”。

每作品贡献收益 = 已交付销售净收入 - 授权/制作分摊/作者收益 - 支付退款争议 - 分发审核客服 - 归属获客成本。订单额、充值额和利润不是同一指标。先验证试玩开始、试玩完成、支付成功、购后继续、结局完成、跨作品购买、退款。

## 首版范围

实现作品目录与分类、作品详情、独立试玩、最小账户、单渠道订单、服务端权益、游戏启动、运营审核与版本管理。年龄/地区策略、隐私、内容合法性、支付商接受度是上线前置条件，不以一个 18+ 弹窗代替。

不做：在线制作台、实时 AI 内容、Skill 商城、多引擎双向编辑、统一跨引擎云存档、原生 App、全站会员、复杂社区、自动作者分账。

## 决策理由

一个网站、一个首发游戏模板、一个收费机制。先制作并发行少量完整作品，而不是同时验证工具市场、游戏市场和模型服务三门生意。游戏框架不能取代实际内容和获客验证。
